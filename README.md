# Nabd Gym (khenov-demo-gym)

Mobile demo app for a fictional gym, built by KHENOV. Arabic first, English switchable. All data is fictional and stays on the device.

Stack: Expo SDK 58, React Native, Expo Router, TypeScript, Reanimated, Gesture Handler, SVG, i18next.

## Run

```powershell
npm install
npx expo start
```

- Android: install Expo Go from the Play Store (it must support SDK 58), scan the QR code.
- Web: press `w` in the terminal, or run `npm run web`.

## Scripts

- `npm run check`: typecheck, lint and format check
- `npm run format`: apply Prettier
